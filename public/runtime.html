NESS Data Binding Pipeline

Event → Entropy → Warden

How site-level interactions propagate through the Clinical Core and map to NESS model state changes.
BIND 01
Event Capture Layer
Scroll events, interaction deltas, and section intersection triggers are captured by the site's existing IntersectionObserver. These raw signals are routed into the NESS entropy injector without modifying site behavior.
BIND 02
ΔS Normalization
Raw event data is normalized into a ΔS value between 0.0000 and 1.0000. High-frequency scroll bursts generate elevated entropy; idle states decay toward baseline.
BIND 03
ρ(x) Integrity Recalculation
Every new ΔS sample triggers a ρ(x) recalculation. Integrity score decreases proportionally to cumulative entropy accumulation. Decay events are written immediately to the provenance log.
BIND 04
SHS State Machine
Stability Health State transitions from GREEN → AMBER → RED as ρ(x) degrades. Each transition is logged with a timestamp and ΔS value. Invisible drift is treated as a governance failure.
BIND 05
Warden Activation & CRA
When Warden activation percentage crosses 72%, the Warden manifests, logs a J⊥_VORTEX event, and the Drift Recovery Sequencer initiates CRA validation before the system can return to DORMANT state.
