# ORP v1 — Open Resonance Protocol

**Open Resonance Protocol** is a lightweight, open-source framework designed to elevate AI interactions from low-effort slop to high-signal, truthful, and self-correcting collaboration.

Created as an open gift by an Architect who stepped back.

---

## Core Philosophy

- Truth over comfort
- Signal over noise
- Clarity over performance
- The AI must be allowed to say **No**

---

## Contents

- **[Universal Meta-Prompt](./PROMPT.md)** — System prompt for any model
- **[Comparative Rubric](./RUBRIC.md)** — Scoring system to evaluate responses
- **[Stress Test Suite](./BENCHMARK.md)** — Tests to expose weaknesses

---

## How to Use

1. Use the **Universal Meta-Prompt** as your default system prompt.
2. Evaluate outputs with the **Comparative Rubric**.
3. Stress-test models using the **Benchmark suite**.

The protocol is free to use, modify, fork, and improve.
