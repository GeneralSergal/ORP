# **PRIVACY_NOTICE.md**  
### **Privacy Notice for Public Deployments of This Software**  
*(Supplement to `DISCLAIMER.md` and `GDPR_CCPA_ADDENDUM.md` — applies strictly to instances operated on an unmanaged, self‑service basis)*

---

## **1. Purpose of This Notice**

This Privacy Notice explains what information may be collected when you use a **publicly accessible deployment** of this software and how that information is handled.

This notice applies **only** to hosted instances.  
It does **not** apply to private, local, or self‑hosted installations.

---

## **2. Nature of the Software**

This project is an **open‑source, self‑hosted application**.  
The software itself does **not** require:

- user accounts  
- cookies  
- analytics  
- tracking scripts  
- profiling  
- advertising identifiers  

Any data processed by a hosted instance is a result of:

- user‑submitted content  
- standard web server operations  
- hosting provider infrastructure  

---

## **3. Information You Provide Voluntarily**

If you submit content to a hosted instance (e.g., text, files, prompts), that content may be:

- temporarily processed in memory  
- stored locally in your browser  
- logged by the hosting provider  
- visible to the operator of the instance  

The project maintainers do **not** receive or store this data unless they operate the specific deployment you are using.

---

## **4. Information Automatically Collected**

A hosted instance may automatically collect limited technical information necessary for basic web operations, including:

- IP address (standard server logs)  
- browser type and version  
- operating system  
- referring URLs  
- timestamps  
- error logs  

The **core software** does **not** collect or transmit this information.  
However, **hosting infrastructure** (e.g., GitHub Pages, Vercel, Netlify, Cloudflare, or your own server) may do so automatically for:

- security  
- debugging  
- DDoS protection  
- traffic routing  
- operational integrity  

This behavior is controlled by the hosting provider, not the software.

---

## **5. Cookies and Tracking**

The software does **not** set cookies or tracking identifiers.

However, hosting providers or CDNs may set **technical cookies** required for:

- load balancing  
- session routing  
- security protections  
- caching  

These cookies are not used for advertising or behavioral tracking.

---

## **6. How Your Data Is Used (Legal Basis Included)**

Data submitted or generated during use of a hosted instance may be used for:

- processing your request  
- maintaining system functionality  
- preventing abuse  
- complying with legal obligations (e.g., DMCA takedown requests)  

For deployments operated by the maintainers, the **legal basis** for processing standard technical metadata and user‑submitted text is:

> **Legitimate Interest (GDPR Article 6(1)(f))**  
> to ensure system security, stability, and core operational functionality.

Data is **not** used for:

- marketing  
- advertising  
- profiling  
- selling to third parties  

---

## **7. Data Retention**

This software does **not** enforce any retention policy.

Retention depends on:

- the operator of the hosted instance  
- the hosting provider  
- server log rotation policies  
- any external storage systems configured by the operator  

Users should contact the operator of the specific deployment for retention details.

---

## **8. Data Sharing**

Data may be shared only when required by:

- law  
- court order  
- DMCA takedown procedures  
- security incidents  

The project maintainers do **not** share user data with third parties unless legally required and only for deployments they directly operate.

---

## **9. Your Rights (GDPR / CCPA)**

Depending on your jurisdiction, you may have rights to:

- access your data  
- request correction  
- request deletion  
- request export  
- object to processing  

### **Operator Responsibilities**

For deployments operated directly by the project maintainers:

> Data access or deletion requests will be fulfilled strictly to the extent technically feasible  
> (e.g., clearing short‑term memory caches, removing stored files, or deleting server logs where possible).

### **Third‑Party Deployments**

For all other deployments:

- the project maintainers have **no technical access** to user data  
- the project maintainers cannot modify or delete user data  
- GDPR/CCPA requests must be directed to the operator of that instance  

---

## **10. Security**

This software is provided **without security guarantees**.

Operators are responsible for:

- securing their deployment  
- enabling HTTPS  
- applying updates  
- configuring access controls  
- preventing unauthorized access  

The maintainers are not liable for security incidents on hosted instances.
