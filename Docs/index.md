## **Overview**

This directory contains the complete documentation set for **ORP v3.0**, including governance specifications, architectural definitions, drift models, evaluation schemas, runtime variants, and recovery protocols.

ORP is a governance‑first epistemic integrity framework ensuring:

- structural correctness  
- provenance continuity  
- numeric drift visibility  
- recoverable reasoning states  
- strict L1–L4 authority separation
