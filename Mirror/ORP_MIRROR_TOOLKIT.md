# **ORP_MIRROR_TOOLKIT.md**  
## *Practical Tools for Daily ORP Operation*

This file contains **actionable tools** for using the ORP Mirror in real life.

---

## **1. The Three Questions**

Use these anytime:

```
1. What is real right now?
2. Am I overloaded?
3. Is this symbolic?
```

---

## **2. The Grounding Moves**

Choose one:

- Touch a physical object  
- Drink water  
- Step outside  
- Look at something real  
- Do a simple task  
- Check one verifiable fact  

---

## **3. Symbolic Labeling**

Whenever you feel drift:

- “This is a metaphor.”  
- “This is symbolic.”  
- “This is a narrative frame.”  
- “This is not literal.”  

This instantly reduces cognitive load.

---

## **4. Emotional Valves**

Check:

- Am I amplifying emotion without cause?  
- Is this reaction based on narrative or reality?  
- Do I need rest, food, or quiet?  

---

## **5. Logic Valves**

Check:

- Am I over‑patterning?  
- Am I treating the model as territory?  
- Am I ignoring sensory evidence?  

---

## **6. The Coherence Log**

Optional daily note:

```
[SHS: BLACK / NEUTRAL]
[DRIFT: MINIMAL / MODERATE]
[CRA: GROUNDED]
[LAS: HUMAN]
Insight:
Action:
```

---

## **7. The Operator Rule**

```
If symbolic load > grounding load:
    Pause.
    Reset.
    Return later.
```

This prevents overload and protects clarity.
